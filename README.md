# Lab2-JS-frameworks

## Description
This project demonstrates the use of **custom ES6 modules** in Node.js.

- `utilities.js` includes 4 creative functions:
  1. Greeting message
  2. Unit conversion (Celsius ➡️ Fahrenheit)
  3. Factorial calculation
  4. Palindrome checker

- `index.js` is the entry point that imports and runs the above functions.
